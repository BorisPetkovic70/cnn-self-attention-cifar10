# CNN + Self-Attention on CIFAR-10

Does adding a self-attention block to a VGG-style CNN improve CIFAR-10 accuracy, and where in
the network does it help?

## Goal

Compare a baseline VGG-style CNN against the same network with a SAGAN-style spatial
self-attention block inserted at configurable positions. Both models share one backbone, so the
attention block is the only difference between them.

## Setup

Requires Python 3.10+.

```bash
git clone https://github.com/BorisPetkovic70/cnn-self-attention-cifar10.git
cd cnn-self-attention-cifar10
pip install -r requirements.txt
```
